## 2026-03-19 - Added aria-label to CircularProgress\n**Learning:** Standalone CircularProgress components used as loading indicators (e.g., in asynchronous operations or initial data loads) must include an explicit aria-label attribute (e.g., aria-label="Loading WASM Engine") to prevent vitest-axe accessibility violations.\n**Action:** Always add aria-label attributes to CircularProgress components used for loading states.
