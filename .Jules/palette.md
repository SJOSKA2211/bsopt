## 2024-03-11 - Add aria-labels to interactive elements\n**Learning:** Interactive filtering controls (like `TextField` and `ToggleButtonGroup` in Material UI) frequently lack accessible names if they only rely on placeholder text or inner toggle buttons. For Material UI `TextField`, the `aria-label` must be applied using `inputProps` (not `InputProps` which is for the wrapper element) to ensure the underlying `<input>` element receives the label correctly.\n**Action:** When adding or reviewing filter inputs and toggle groups, verify they have explicit `aria-label` attributes to support screen reader users, keeping in mind the structural properties of MUI components.
