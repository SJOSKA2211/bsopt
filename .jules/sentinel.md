## 2026-04-19 - Removed hardcoded API key from config in Auth Service
**Vulnerability:** A hardcoded default JWT secret was present in `src/auth/grpc_server.py` as a fallback value (`os.getenv("JWT_SECRET", "super-dev-secret-change-me-in-prod")`), which could be exploited in production if the environment variable is not explicitly set.
**Learning:** Hardcoded fallback values for cryptographic secrets are extremely dangerous because they can silently allow insecure defaults to be used in production environments. We must rely on strict configuration management (e.g. `pydantic-settings`) that explicitly fails to start if secrets are missing. Moreover, when removing such variables, replacing them with a secure configuration value (`settings.JWT_SECRET`) instead of simply deleting them prevents `ImportError` or `NameError` if they happen to be imported elsewhere.
**Prevention:** Do not provide default string values for any secrets in `os.getenv` or `pydantic`. Use `pydantic.Field(...)` to enforce presence, and directly reference these centralized settings (e.g. `settings.JWT_SECRET`) instead of reading from `os.getenv` locally in the file.
