# Phase 4: Ray Multi-Node Distribution & Optimization Plan

## Overview
Enable scalable multi-node training by making `src/ml/trainer_v2.py` "Ray-aware" and updating `src/ml/distributed_training.py` to leverage it correctly.

## Current State Analysis
- `src/ml/trainer_v2.py` initializes MLflow and manages device placement in `__init__`, causing conflicts when instantiated by multiple Ray workers.
- `src/ml/distributed_training.py` wraps the model in DDP but then `Trainer` attempts to move it to device again.

## Implementation Approach
Refactor `Trainer` to accept a `distributed_context` flag. If true, it delegates logging, checkpointing, and device management to the orchestration layer (Ray Train) or conditionally executes them only on Rank 0.

## Phase 1: Refactor Trainer V2
### Overview
Modify `src/ml/trainer_v2.py` to support external orchestration.

### Changes Required:
#### 1. `src/ml/trainer_v2.py`
**Changes**:
- Update `__init__`: Add `is_distributed: bool = False`.
- **Conditionals**:
    - Only call `mlflow.start_run()` if `not is_distributed` OR if explicitly handled (e.g., passing run ID). For Ray, we might rely on the driver to set the run, or just disable internal MLflow start.
    - Only call `self.model.to(device)` if `not is_distributed`.
- Update `_handle_epoch_end`:
    - If `is_distributed`, check rank. If Rank != 0, skip logging/checkpointing.
    - If `is_distributed`, call `ray.train.report(metrics)`.
- Update `_save_checkpoint`:
    - Handle unwrapping `model.module` if it exists (DDP).

```python
# src/ml/trainer_v2.py

try:
    import ray.train
    HAS_RAY = True
except ImportError:
    HAS_RAY = False

class Trainer:
    def __init__(self, ..., is_distributed: bool = False):
        self.is_distributed = is_distributed
        # ...
        if not self.is_distributed:
            self.model = model.to(device)
            mlflow.set_experiment(experiment_name)
            self.run = mlflow.start_run()
        else:
            self.model = model # Assumed already on device/wrapped
            # MLflow run assumed managed externally or we attach to existing? 
            # For now, disable internal run start to avoid collision.

    def _handle_epoch_end(self, ...):
        # ... logic ...
        if self.is_distributed and HAS_RAY:
            ray.train.report({"train_loss": train_loss, "val_loss": val_loss})
            
        if self.is_distributed:
            if ray.train.get_context().get_local_rank() != 0:
                return # Skip logging/checkpointing for non-rank-0
```
