# Optimize Startup Scripts Implementation Plan

## Overview
Improve logging and error reporting in the dev stack launcher.

## Current State Analysis
- Health checks silence all output, making failures opaque.
- RabbitMQ health check is missing or incomplete.

## Implementation Approach
1. Refactor `check_health` to report which service is failing.
2. Add explicit RabbitMQ health check.
3. Use a more robust wait loop.

## Phase 1: Script Enhancement
### Overview
Update `scripts/start_all_dev.sh`.
### Changes Required:
#### 1. scripts/start_all_dev.sh
**Changes**: Update `check_health` and the wait loop.
### Success Criteria:
#### Manual:
- [ ] `./scripts/start_all_dev.sh` prints which service it's waiting for.
- [ ] Failure of one service results in an explicit error message.
