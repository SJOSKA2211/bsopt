# Fix Postgres Schema and Missing Functions Implementation Plan

## Overview
Mount initialization scripts to the Postgres container and ensure the schema is correctly applied to the existing volume.

## Current State Analysis
- `docker-compose.dev.yml` lacks a mount for `./init-scripts` to `/docker-entrypoint-initdb.d`.
- Existing `postgres_data_dev` volume may already be initialized, preventing the entrypoint script from running again.

## Implementation Approach
1. Update `docker-compose.dev.yml` to include the volume mount.
2. Provide a manual way to apply scripts if re-initialization isn't desired (e.g., via `docker exec`).

## Phase 1: Docker Compose Update
### Overview
Add the initialization script mount to the `postgres` service.
### Changes Required:
#### 1. docker-compose.dev.yml
**Changes**: Add `./init-scripts:/docker-entrypoint-initdb.d:ro` to the `volumes` list of the `postgres` service.
```yaml
  postgres:
    image: postgres:15-alpine
    ...
    volumes:
      - postgres_data_dev:/var/lib/postgresql/data
      - ./init-scripts:/docker-entrypoint-initdb.d:ro
```
### Success Criteria:
#### Automated:
- [ ] `docker compose -f docker-compose.dev.yml config` passes validation.
#### Manual:
- [ ] `docker compose -f docker-compose.dev.yml exec postgres ls /docker-entrypoint-initdb.d` shows the SQL scripts.

## Phase 2: Manual Schema Application
### Overview
Apply the missing function and columns to the existing database to avoid data loss from a full volume reset.
### Changes Required:
#### 1. Manual SQL Execution
**Changes**: Run `psql` inside the container to apply `00-core-schema.sql` and `07-market-stats-mv.sql`.
```bash
docker compose -f docker-compose.dev.yml exec -T postgres psql -U admin -d bsopt < init-scripts/00-core-schema.sql
docker compose -f docker-compose.dev.yml exec -T postgres psql -U admin -d bsopt < init-scripts/07-market-stats-mv.sql
```
### Success Criteria:
#### Automated:
- [ ] `SELECT refresh_market_stats();` returns success.
- [ ] `SELECT delta FROM options_prices LIMIT 1;` returns success (even if empty).
